# TOTVS TIR

## Instalação

- Instalação Python [Instalação Python e TIR](https://www.python.org/downloads/)

Instalação TIR via cmd:

```py
pip install tir_framework --upgrade
```

Testes pós instalação cmd:

```py
pip show tir_framework
```
